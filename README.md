# Ed Ryan

Lead Software Architect in Boston, working on safety-critical medical software. Over twelve years I've moved from
verification and validation, through full-stack development, to architecture, all on distributed patient monitoring
systems in a regulated environment.

## What I focus on

- **AI-augmented engineering**: automated code review and agent tooling that engineers can trust
- **Standards-based interoperability**: IHE HL7 and IEEE 11073 SDC in place of proprietary interfaces
- **Cloud migration** of distributed on-premise systems where uptime and patient safety come first

## Currently building

**[coding-agent-skills](https://github.com/EJRyan89/coding-agent-skills)**: portable skills for Claude Code, Codex
CLI, and GitHub Copilot CLI, including a structured pull request review pipeline. The deployer is built the way
regulated software is: every change is validated before it touches disk, journaled so it can roll back, and tracked
by ownership so it never overwrites what it didn't install.

Most of my work lives in private repositories; this is the public corner of it.
